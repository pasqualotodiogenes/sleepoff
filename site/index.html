Timer de desligamento automático
construído sem concessões.

Um utilitário CLI e TUI em Go para programar o desligamento do computador sem riscos. Modo interativo reativo, suporte multiplataforma (Windows, macOS, Linux), ajuste em runtime e tela de pânico de 10s com cancelamento instantâneo.

Engenharia de precisão para sua máquina

Construído em Go estrito, sem abstrações infladas ou dependências em runtime desnecessárias.

⚡

Zero Bloat & CGO_ENABLED=0

Binário único estático e enxuto. Inicialização instantânea em <5ms, consumo de memória na faixa de 8MB e sem runtimes externas instaladas.

🛡️

Proteção Anti-Desligamento Acidental

Contagem regressiva de pânico de 10 segundos antes do shutdown, com alertas sonoros crescentes e cancelamento com duplo 'c' para garantir que você nunca perca seu trabalho.

💻

Multi-Plataforma Nativa

Integração com chamadas reais de sistema isoladas por build tags: Win32 Mutex e Tray no Windows, POSIX flock e systemctl no Linux, osascript no macOS.

⌨️

Dupla Interface de Uso

Abra a TUI interativa Charm Bubble Tea para escolher períodos amigáveis ou dispare via CLI direta: sleepoff 45m ou sleepoff 1h30m.

🧪

Modo Teste Seguro (--dry-run)

Teste e valide toda a jornada, animações e fluxos de contagem sem receio. O switch --dry-run simula o encerramento sem invocar o desligamento do OS.

🔊

Sintetizador Sonoro de Precisão

Alertas audíveis precisos a 800Hz e beeps progressivos no modo pânico para avisar mesmo se a janela estiver minimizada no background.

Instalação Imediata

Escolha sua plataforma e instale o sleepoff em poucos segundos com comandos oficiais.

Via Winget (Recomendado)
winget install pasqualotodiogenes.sleepoff
Via PowerShell (Instalador Inno Setup)
irm https://github.com/pasqualotodiogenes/sleepoff/releases/latest/download/sleepoff-setup.exe -OutFile sleepoff-setup.exe; .\sleepoff-setup.exe
Via Go
go install github.com/pasqualotodiogenes/sleepoff@latest
Via Shell Script (Apple Silicon & Intel)
curl -fsSL https://raw.githubusercontent.com/pasqualotodiogenes/sleepoff/main/scripts/install.sh | bash
